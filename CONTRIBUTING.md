# Contributing

Open an issue or prepare a change with the release version, affected module, scientific rationale and the exact input/output fields changed. Preserve the frozen reference files and candidate definitions when making implementation-only changes. A scientific change to eligibility, a correction family or a candidate set requires a new version and updated Methods, tables, figures and provenance together.

Run the module in a fresh output directory and attach its numerical status and log. Update the file manifest only after reviewing intentional file changes. Avoid committing raw public datasets, credentials, signed URLs, local caches or generated run directories. Public repository location and contributor permissions are managed by the research team.
