# 05 — External 8-µm Visium HD validation

> Code/data-only distribution (0.2.1): rendered article figures, supplementary
> workbooks and manuscript text are not shipped. Any graphics generated by the
> commands below are local run products, not repository attachments.

This module independently evaluates the frozen Core47, Spatial43, Convergent9 and Extended13 sets in **P1CRC, P2CRC and P5CRC**. The release includes compact raw candidate-count matrices for all **1,595,565 source bins**, complete-library denominators, barcode/grid metadata, feature mappings, verified per-gene metric checkpoints, current ST12 reference sections, source-data CSVs and executable code.

## Run

```bash
# Fast route: reaggregate verified gene metrics, rerun all statistical tests,
# generate 40,000 matched-null draws, and redraw Figure 5.
python analysis/05_external_visium_hd/run.py --mode processed --output-dir results/05_processed

# Offline count route: also recalculate all gene-level regional and Moran metrics.
python analysis/05_external_visium_hd/run.py --mode counts --output-dir results/05_counts

# Raw-source route: extract the candidate counts and COMPLETE library sizes first.
python analysis/05_external_visium_hd/run.py --mode raw \
  --raw-dir /path/to/visium_hd_sources --output-dir results/05_raw
```

Both processed and count routes use only included checkpoints and do not require a network connection. The raw route expects `P1CRC_filtered_feature_bc_matrix.h5`, `P1CRC_Metadata.parquet.gz` and the correspondingly named P2CRC/P5CRC files. Source URLs and SHA-256 values are in `config/source_files.csv`. An extraction-only command is also supplied:

```bash
python analysis/05_external_visium_hd/scripts/extract_source_counts.py \
  --raw-dir /path/to/visium_hd_sources \
  --output-dir analysis/05_external_visium_hd/data/counts
```

The tested release used the three verified public H5 files to extract all count checkpoints, then executed the count route. No fresh alignment or tissue annotation was performed. Raw H5 files are not duplicated in the repository because the compact checkpoints are sufficient for offline numerical reconstruction and the original files remain available from GEO.

## Normalization, compartments and spatial graph

Counts are normalized by complete bin-level library sizes and transformed as `log2(CPM + 1)`. Source zero-library bins are retained with zero expression. Their numbers are 1,600 in P1CRC, 63 in P2CRC and 22 in P5CRC. Every matrix barcode is joined to the source metadata; duplicate metadata barcodes are rejected. The frozen source `Periphery` annotations define `Tissue`, `Tumor` and `50 micron` regions.

The tumour endpoint is mean expression in `Tumor` plus `50 micron` minus mean expression in `Tissue`. The boundary endpoint is mean expression in `50 micron` minus mean expression in `Tumor`. The remaining tissue is not asserted to be histologically normal colorectal epithelium.

Global Moran's I is calculated on the binary, non-row-standardized four-neighbour square grid parsed from the 8-µm source barcodes. Each undirected edge is stored once; the formula includes the equivalent symmetric-graph scaling. Graph edges are 1,011,093, 1,088,678 and 1,080,961 in P1CRC, P2CRC and P5CRC, respectively. Bins are not independent biological replicates.

## Explicit P1CRC correction

The recorded P1CRC H5 hash and source region counts reproduce exactly. Direct reconstruction from those sources yields **1,011,093 edges**, whereas the recovered original hard-coded summary stated 997,062. Its old expression summaries also do not reproduce. The current code consistently uses freshly reconstructed P1CRC measurements throughout the gene, set, graph and concordance outputs. For example, Core47's current P1CRC mean tumour effect is 0.5257990696 and mean Moran's I is 0.03975817975. Neither quantity is taken from the invalid original hard-coded summary.

P2CRC/P5CRC gene-level mean expression, detection and Moran metrics reproduce their independently archived source checkpoints. The set-level summaries are recomputed after propagating Spatial43, Convergent9 and Extended13 membership by gene key.

## Biological units, denominators and tests

There are 455 evaluable candidates per tumour. Set-specific denominators are 43/47 Core47, 40/43 Spatial43, 8/9 Convergent9 and 12/13 Extended13 genes. Each set mean weights evaluable genes equally within a tumour; three-tumour inference treats tumour as the unit of replication.

Twelve one-sided exact Wilcoxon tests comprise three endpoints across four sets. The archived alternatives are `greater` for tumour enrichment and Moran's I, and `less` for peripheral-minus-interior expression. These directions are described as retained analysis choices, not newly claimed to have been preregistered. BH correction covers the complete 12-test family. With three tumours, the smallest one-sided exact probability is 0.125; all current tests and their BH values equal 0.125. No bin-level sample size is substituted for three biological observations.

The matched-null sensitivity analysis retains the historical P2CRC/P5CRC-only scope. Each gene's expression, detection and Moran metrics are averaged with equal tumour weights. Background and target genes are grouped into joint expression/detection quintiles using `pandas.qcut(..., duplicates='drop')`. The target set is excluded from its background. Within a draw, target genes are visited in seeded random order and matches are sampled without replacement. A depleted bin falls back to the nearest available genes in standardized expression/detection space, using the retained up-to-50-neighbour rule. The seeds are 20261011, 20261012, 20261013 and 20261014 for Core47, Spatial43, Convergent9 and Extended13. All 40,000 draws are newly computed by either run mode.

The plus-one empirical probabilities are 0.0424957504, 0.0132986701, 0.0914908509 and 0.1795820418. These sensitivity probabilities are not substituted for the three-tumour biological-replication tests. Discovery/external and P2/P5 Spearman concordance tests use a separate complete family of eight probabilities.

## Validation

Every completed run writes `status.json` with boolean `passed` and exits nonzero if validation fails. Comparisons use `rtol=1e-8`, `atol=1e-10`, matching missingness, and exact strings/booleans. This accommodates negligible floating-point summation differences while remaining far below reporting precision. The checks compare all regenerated ST12 sections, all 466 P2/P5 metric rows and source hashes, dimensions, regions and graph edge counts. The matching sequence also reproduces the recorded exceedance counts **424, 132, 914 and 1,795** exactly.

Scientific invariants check three source sample sizes totaling 1,595,565, the corrected P1 graph, 455 evaluable genes per tumour, three unavailable HMGB1 observations, all 24 observed Convergent9 tumour effects and Moran values positive, all 24 observed boundary effects negative, and all 12 exact-test BH values equal to 0.125. Tests are in `tests/test_scientific_invariants.py`; their purpose is to catch inferential or unit-of-analysis errors, not to validate hard-coded constants in place of computation.

## Dependencies and outputs

Processed mode requires NumPy, pandas, SciPy and Matplotlib. Count mode currently imports the extraction module and therefore also requires h5py; it does not read Parquet. Raw extraction additionally requires pyarrow. The executed environment used h5py 3.15.1 and pyarrow 23.0.1; the repository environment lock records the other exact versions. `OPENBLAS_NUM_THREADS=1` and `OMP_NUM_THREADS=1` can prevent oversubscription when running several modules at once.

Outputs include all current external tables, the 40,000 null values, sample QC, 27 Convergent9 rows including three unavailable HMGB1 rows, four Figure 5 source-data CSVs, and new SVG/PNG rendering. The user's current reference SVG is retained separately at repository level.
