# Licensing and third-party attribution

No blanket licence is imposed on the contents of this scientific archive.

The supplied cell-line matrix does not identify its DepMap release or upstream
redistribution terms. The repository preserves that uncertainty and does not
claim that the data are CC0, CC BY, or covered by a software licence.

The recovered organoid values and metadata remain attributable to Broad DepMap
and the referenced study/dataset. Their applicable upstream terms are not replaced
by the licences of repository scripts. Control lists and upstream code references
retain their original provenance. The distribution includes links to the pinned
Chronos implementation rather than assigning ownership of that implementation.

The root LICENSE records MIT for original project-specific code. Applicable
data redistribution terms must still be established before public release.
GitHub publication is not itself a licence grant for third-party material. A
repository citation file is included, but no publication DOI or repository URL
has been invented. No font files, credentials or private patient-level records are
included by this packaging step.
