# Module 06 — CRC16 niches, bacteria and cellular attribution

> Code/data-only distribution (0.2.1): rendered article figures, supplementary
> workbooks and manuscript text are not shipped. Any graphics generated by the
> commands below are local run products, not repository attachments.

This module reruns the current **Spatial43 / Convergent9** analysis from the
published processed source measurements and archived, explicitly identified
checkpoints. It includes executable statistical code, all spot-level inputs,
the complete 13-niche assignments, the revised 12-block CMH partition, and
independent patient-level attribution. It does not recluster CRC16.

```bash
python analysis/06_crc16_niches/run.py --mode processed --output-dir results/06_crc16_niches
```

The runner writes numerical validation, separate refitted/publication-precision
tables, all Figure 6 source tables, an editable SVG and PNG, and `status.json`.
The status is true only after the new calculations agree with the current
Supplementary Table 13 and satisfy the stated denominators.

## Source-object extraction

`extract_crc16.py` verifies the RDS checksum before using the `rdata` parser to
read its Spatial assay and metadata. It preserves the source matrix orientation
and checks all-feature library sizes against source metadata. R integer missing
values are explicitly decoded. R code is not executed.

```bash
python analysis/06_crc16_niches/extract_crc16.py \
  --rds /path/to/ST.seu.rds \
  --frozen-niches analysis/06_crc16_niches/input/CRC16_frozen_niches.csv \
  --reference-sizes analysis/06_crc16_niches/provenance/bacterial_burden_by_niche.csv \
  --output-dir regenerated_crc16_inputs
```

The GSE178341 source HDF5 is shared with module 03. Its extractor generates this
module's nine-gene cell checkpoint without loading a huge compressed chunk into
RAM. Complete cell libraries are calculated over all 43,113 source features.

```bash
python analysis/03_single_cell/code/prepare_pseudobulk.py \
  --h5 /path/to/GSE178341_crc10x_full_c295v4_submit.h5 \
  --output regenerated_pseudobulk \
  --expanded-dir /path/to/temporary_expanded_cache \
  --c9-cell-output regenerated_C9_cell_counts.npz
```

The optional RDS extractor additionally requires `rdata==1.0.0` and its xarray
dependency. The ordinary processed run uses NumPy, pandas, SciPy, scikit-learn,
threadpoolctl and Matplotlib. The optional HDF5 extraction also uses h5py.

## Frozen niche recovery and provenance boundary

The original clustering executable was **not recovered**. The original 13-niche
assignment was recovered from the archived vector map and aligned bijectively
to all 3,106 source coordinates. The largest coordinate discrepancy is below
0.000014 pixels. Every niche size and the original 35 genes' expression effects
agree with their archived values. The rerun retains these assignments.

The old METHODS and stability/coherence/marker files in `provenance/` preserve
the archived construction description and results. They do not imply that the
original clustering or stability scan was rerun. Old Spatial35/Convergent6 names
inside the provenance records identify historical inputs; current calculated
outputs use Spatial43/Convergent9.

## Statistical analysis

**Host expression.** Full-library CPM is transformed as log2(CPM + 1). The
43 × 13 gene effects compare each niche with the remaining spots. Convergent9
and the seven explicitly recovered immune-context programmes use gene-wise
population-standard-deviation scaling across the full section; zero-variance
genes contribute zero. The seven immune-context gene lists are exported with
the results and all 91 programme effects are recalculated from counts.

**Bacterial QC.** Missing taxonomic counts are reconstructed as zero and singleton
taxon–spot counts are suppressed. The exact archived retained-feature membership
is used as a frozen QC input, preserving 295 features, 80,272 UMIs and 720 occupied
spots. The runner exports all retained/excluded labels and checks each taxon's
total and prevalence against the archived QC table. It does not reconstruct
unrecorded reasons for individual contaminant/non-bacterial exclusions. Total
burden includes all retained features, including taxa ineligible for testing.

**Primary occupancy.** Twenty eligible taxa (≥20 UMIs and ≥10 spots) are crossed
with 13 niches. Newton fits estimate unpenalised logistic models with niche,
log1p non-focal bacterial burden, log1p full host library and population-scaled
image coordinates x, y, x², y² and xy. There are 260 planned tests, 166 estimable
and 94 separated fits. Unavailable estimates/P/q remain missing; computational
P=1 padding is used only to preserve the 260-test BH family. Global occupancy
and OLS log1p burden are separate 13-test families. OLS uses classical covariance
and two-sided residual-degrees-of-freedom t probabilities.

**CMH sensitivity.** A revised coordinate-only partition uses raw imagecol and
imagerow pixels: k-means++, 12 clusters, seed 42, 20 initialisations, max_iter 300,
tol 0.0001, Lloyd algorithm, one thread. It is explicitly a documented revised
partition, not recovery of the unavailable historical block assignment. The
runner exports all barcodes, centres and 3,120 per-block 2×2 tables. CMH uses no
continuity correction or pseudo-count, and `chi2.sf` yields the P value. BH
covers all 240 finite P values, including boundary OR cases; 20 zero-variance
tests remain unavailable. Robustness requires primary q<0.05, CMH q<0.10,
concordant finite positive OR direction and ≥5 positive spots in each group.

**Other bacterial analyses.** Conditional abundance compares log2(UMI + 1)
among positive spots using Mann–Whitney tests, requiring at least three positives
in each group; BH covers 119 evaluable contrasts. Higher-complexity sensitivity
retains 1,896 spots with ≥500 host UMIs and ≥200 detected host features, uses the
full-section spatial scaling, and yields eight eligible taxa / 104 planned
tests / 55 estimable fits. Its BH adjustment preserves the planned 104-test family.

**Numerical precision.** Independent Newton coefficients agree with the current
reference to approximately 6.3×10⁻¹⁰. Wald probabilities differ by at most
2.7×10⁻⁶ in the primary family and 4.4×10⁻⁶ in the higher-complexity family.
Both the refitted values and already-reviewed publication precision are retained
as separately named files. Publication-precision primary coefficients/P/q are
used for the Figure 6D display only after the numerical comparison passes.
Gene effects, immune scores, CMH and conditional-abundance results agree to
floating-point precision. There is no substitution for non-estimable models.

## Independent cellular attribution

The Convergent9 programme is fully recomputed from the nine source gene counts,
complete libraries and original annotations at all three annotation levels.
Patient–population profiles require ≥20 cells. Scaling uses every retained
profile within a level; display requires ≥5 patients, without excluding rare
profiles from standardisation. The broad lineage counts are 62 epithelial,
62 T/NK/ILC, 62 myeloid, 52 B-cell, 42 plasma-cell, 55 stromal and 39 mast-cell
patients. There are 62 distinct tumour patients.

The other seven historical cellular-attribution programmes start from the
recovered patient-score checkpoint. **Their original gene definitions have not
been recovered.** No gene list has been guessed. Their broad-lineage summaries
and the five affected paired contrasts are reproducible from patient scores;
historical intermediate/fine summaries are preserved as attributed checkpoints.
The six prespecified lineage tests compare each target score with the unweighted
mean of other available broad lineages within a patient, use paired two-sided
Wilcoxon tests and BH across six. The recalculated tests match the current ST13.

CRC16 is one section from one patient. The 3,106 spatial locations are not
independent patient replicates. GSE178341 provides cellular attribution, was
independent of CRC16, and also contributed to earlier candidate prioritisation.
Neither analysis establishes microbial viability, causation or treatment benefit.
