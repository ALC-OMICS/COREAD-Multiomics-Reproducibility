# Module 03 — patient-level single-cell prioritization

> Code/data-only distribution (0.2.1): rendered article figures, supplementary
> workbooks and manuscript text are not shipped. Any graphics generated by the
> commands below are local run products, not repository attachments.

The original archive contained numerical results, figure helpers and validation code, but not the inference implementation. This module now includes a clearly identified reconstruction from the public GSE178341 processed UMI matrix, source cellular annotations and frozen 466-gene feature mapping. The new code was written on 2026-10-31 and is not represented as recovered historical code.

## Run from included processed checkpoints

```bash
python analysis/03_single_cell/run.py --mode processed --output-dir /path/to/new/single-cell-run
```

The included checkpoint contains integer candidate counts and positive-cell counts for 671 patient/specimen/top-lineage pseudobulks and 969 epithelial fine-cluster pseudobulks. Metadata contains complete-feature UMI library sizes and cell counts. This checkpoint was derived in the current reconstruction from all 43,113 features and 370,115 cells; library sizes were not calculated from the candidate subset. A SHA-256 manifest protects the checkpoint.

Every processed run recomputes the patient-level comparisons, multiplicity adjustments, prevalence, descriptive specificity, tier assignments and Core47 membership. It produces a boolean `passed` in `status.json`, new numerical outputs, current Figure 3, and source data. The current clean run matched 64 derived fields across all 466 candidates (29,824 values), with maximum numerical difference 4.55 × 10⁻¹³ against the independent frozen reference. The 47-gene core and tier counts 65/134/267 were recovered exactly.

## Rebuild the checkpoint from public counts

Download [the processed GSE178341 HDF5 matrix](https://ftp.ncbi.nlm.nih.gov/geo/series/GSE178nnn/GSE178341/suppl/GSE178341_crc10x_full_c295v4_submit.h5) and run:

```bash
python analysis/03_single_cell/run.py --mode raw --h5 /path/to/GSE178341_crc10x_full_c295v4_submit.h5 --expanded-dir /path/to/scratch/gse-expanded --output-dir /path/to/new/full-single-cell-run
```

Here `raw` denotes reconstruction from the public processed count matrix, not FASTQ alignment or upstream source-study annotation. The required SHA-256 is `f435bb2651ff5297d0c24a99daf58850ed67ae1ed6c5ef05fad48fa3f0186670`. The 1.203 GB source matrix has unusually large shuffled/gzip HDF5 chunks; the implementation expands them on disk in bounded memory. Allow at least 15 GB of scratch disk space. The expanded arrays are temporary and are not part of the repository.

For independent Convergent9 cellular attribution in module 06, the extraction command also supports:

```bash
python analysis/03_single_cell/code/prepare_pseudobulk.py --h5 /path/to/GSE178341_crc10x_full_c295v4_submit.h5 --expanded-dir /path/to/scratch/gse-expanded --output /path/to/new/pseudobulk --c9-cell-output /path/to/new/cell_C9_counts.npz
```

The NPZ contains `genes`, cell-by-gene integer `counts`, complete-feature `library_size`, and HDF5-order `barcodes`. Join the source cluster and clinical metadata by their original cell identifiers.

## Exact analytical conventions

There are 36 tumour/normal epithelial pairs, 35 pairs after requiring at least 100 epithelial cells in each specimen, 33 composition-balanced pairs, and 62 epithelial/non-epithelial tumour pairs. MMR comparisons use 34 MMRd and 28 MMRp patients. The recovered directional significant counts are 219 tumour/normal, 220 in the minimum-cell sensitivity, 198 composition-balanced, and 206 epithelial/non-epithelial; 139 genes have MMR-associated FDR <0.05. Each inferential family is corrected separately across 466 genes.

Top-lineage abundance and tau use mean patient-level CPM. Fine epithelial-state descriptive dominance and tau use pooled CPM, as explicitly recorded by the original `Pooled_CPM` source table. These descriptive fine-state measures do not select Core47. The composition-balanced inferential comparison separately averages shared fine-cluster log2(CPM+1) with equal weights within patients. Historical column names `Primary_tumor_enrichment_robust_ge100cells` and `Primary_tumor_enrichment_robust_composition` encode positive FDR-significant calls in the corresponding sensitivity itself; an intersection with primary significance must be calculated explicitly if needed.

The new bootstrap intervals use 2,000 resamples, seed 20261007, a shared patient-index matrix, lexicographically sorted paired patients and float64 medians. They are labelled `Reconstructed_boot_CI95_low/high`. The original bootstrap random-stream schedule was not recovered; the historical intervals remain in immutable reference tables. Their numerical proximity is reported for information and is not asserted to establish the original schedule.

## Figure 3 correction

The current panel order is A, lineage heatmap; B, expression landscape; C, priority counts; D, MMR comparison. Panel A calculates log2(mean patient-level CPM + 1) exactly once, then a row z-score with sample standard deviation (ddof=1). The legacy helper applied an extra log to an already logged source; its historical copy remains under provenance. The current Figure 3 source data include linear means, single-log values and displayed z-scores.
