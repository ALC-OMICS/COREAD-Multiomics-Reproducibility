# Module 07 — frozen translational appraisal

> Code/data-only distribution (0.2.1): rendered article figures, supplementary
> workbooks and manuscript text are not shipped. Any graphics generated by the
> commands below are local run products, not repository attachments.

This module regenerates the Figure 7 plotting tables and an editable SVG from
the exact current Supplementary Table 14 curation. The inputs are seven CSV
tables extracted from that worksheet plus its quantitative anchors drawn from
current Supplementary Table 13; each input checksum is recorded by the
runner. It does not turn expression scores into predicted treatment benefit.

```bash
python analysis/07_translational/run.py --mode processed --output-dir results/07_translational
```

The program independently derives the evidence-class counts (three A, six B,
one D, no C/E), checks the eight-module by four-niche grid, derives its eight
direct and five conditional edges, and checks that all edges use the same width.
The remaining 19 coverage cells are zero. Source URLs are exported separately
for every strategy and limiting-evidence record.

## Scope of reproducibility

The literature appraisal is a **human-curated input**, not a fitted statistical
model or a systematic-review search. Its evidence cutoff is 14 October 2026,
with targeted checks recorded on 28 October 2026. This rerun preserves that
snapshot. It does not reclassify records using later trial updates. Clinical
evidence statements and limitations must be interpreted with their cited record
and the frozen date; the table does not establish a niche-selected indication.

DT2216 and OMO-103 are class B because the frozen definition includes prospective
human CRC exposure. Their classification does not establish CRC efficacy.
Biomarker-defined approved backbones remain conditional on the clinical
indication. Coverage codes are deterministic mechanistic annotations, with no
response, synergy, survival or drug-sensitivity score calculated.

`status.json` reports numerical and structural validation of this deterministic
reproduction. The repository's published-reference Figure 7 preserves the
supplied layout; this module's SVG independently redraws the same data.
