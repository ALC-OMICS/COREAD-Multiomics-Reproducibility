# 04 — Discovery spatial inference and multimodal integration

> Code/data-only distribution (0.2.1): rendered article figures, supplementary
> workbooks and manuscript text are not shipped. Any graphics generated by the
> commands below are local run products, not repository attachments.

This module reproduces the current **Core47 → Spatial43 → Convergent9** hierarchy and the **Extended13** sensitivity set. The key correction joins every Moran statistic and probability by `Gene` before false-discovery-rate adjustment. It does not assign a list of probabilities to an independently sorted table by row position.

## Run

From the repository root, with the repository Python environment installed:

```bash
python analysis/04_discovery_spatial/run.py --mode processed --output-dir results/04_discovery_spatial
```

An independent directory can be supplied to avoid overwriting bundled results. `--no-plots` omits only SVG/PNG rendering. The process exits nonzero if reference comparisons or substantive numerical checks fail. `status.json` contains a boolean `passed`, the complete comparisons and scope limits.

The processed command starts from section-level Moran measurements, patient-level regional measurements and explicit upstream evidence. It regenerates patient Moran summaries, signed-rank probabilities, BH corrections, spatial categories, the final hierarchy, descriptive integrated scores, ranks, plot values and all Figure 4 panels. The original null vectors are used to recalculate historical matched-null summary statistics.

## Statistical implementation

Regional effects are differences in mean `log2(CPM + 1)` expression. Section replicates had already been averaged within patient in the retained regional-effect checkpoint. The code recomputes gene-wise medians, means, positive-patient fractions and two-sided signed-rank tests after excluding unavailable regional effects. Each endpoint receives its own BH correction over finite probabilities.

For Moran inference, the code first averages the two serial-section measurements within patient and gene. It then tests the resulting patient vector using the original two-sided signed-rank specification. The test retains the original NaN-propagation behavior: a missing patient Moran measurement makes that gene's test unavailable. This yields **441 finite probabilities**. Summaries describe available measurements, while the positive fraction retains the original patient-vector denominator. Changing NaN handling would change the tested family and is therefore not an innocuous implementation choice.

Core47 requires single-cell Tier A membership, a positive composition-balanced expression effect and composition-balanced BH < 0.05. Spatial43 additionally requires positive median Moran's I, Moran BH < 0.05 and positive tumour–stroma direction in at least five of six tumour-bearing patients. Forty-four Core47 genes have positive significant Moran statistics; the directional requirement leaves 43 spatially substantiated genes. Spatial43 excludes GAPDH, BRD4, UBR4 and SMARCD1 from Core47.

The primary orthogonal anchor is COREAD-preferential dependency or patient-DNA top-30 bootstrap frequency ≥ 0.80. Convergent9 is Spatial43 intersected with that anchor. Its members are BCL2L1, CTNNB1, FASN, HMGB1, IRS2, MYC, RNF6, SOX9 and YAP1. Extended13 instead uses COREAD-preferential dependency or patient driver/CNA frequency ≥ 0.05; it adds DDX56, HSF1, PTK2 and RAC1. External measurements do not define these sets.

The descriptive integrated visual score is the mean of six available z-scores: cross-system dependency geometric mean, epithelial-versus-non-epithelial expression, composition-balanced expression, tumour-versus-stroma expression, Moran's I and DNA driver/CNA frequency. Each component is standardized over finite values across the 466-gene catalogue with sample standard deviation (`ddof=1`). Missing components are not imputed. The top-24 heatmap separately standardizes its seven continuous columns within the displayed genes. Neither visual rank nor score defines the hierarchy.

## Historical matched-null limitation

The original analysis used 10,000 expression/detection-matched 47-gene sets and seed 20261008. However, the original code iterated Python sets when ordering target genes and fallback candidates; the hash-dependent iteration order was not saved. A numerical seed alone cannot recover that order. The processed route therefore **replays the archived null vectors**, recalculating observed means, exceedances and `(exceedances + 1)/(10,000 + 1)`. This reproduces the recorded three historical probabilities without pretending that new random draws are identical.

`scripts/recompute_from_raw.py` contains the portable raw-data analysis, including host library normalization, pathology joins, hexagonal adjacency, boundary/distance definitions, composition residualization and section-level Moran calculations. Its fresh matched-null sampling uses **sorted gene order**, making new draws deterministic. These are explicitly new draws, not an exact regeneration of the historical vector. The release also executed the **full source H5AD route**: 20,654 spots, all 14 pathology tables and all 40 Belgian-reference composition factors. It reproduced every one of the current ST11 table's 159 non-key columns across 466 genes, including the refitted composition model and exploratory modules. `validation/full_source_H5AD_status.json` records the passing comparison. The raw route still generates distinct, explicitly labelled canonical-order null draws; historical reported probabilities continue to use the archived vectors.

```bash
python analysis/04_discovery_spatial/scripts/recompute_from_raw.py \
  --h5ad /path/to/sp.h5ad \
  --annotations-dir /path/to/source_pathology_csvs \
  --cell-density /path/to/W_cell_density_q05.csv \
  --upstream-evidence analysis/04_discovery_spatial/data/upstream_gene_evidence.csv \
  --output-dir results/04_from_raw
```

The expected source H5AD SHA-256 is `5c839f4e78b4f334e0c19dd3aef173c332b147b8418e854a0ffb6600e05da79a`. Source metadata describe 20,654 locations, 14 sections and seven patients, including six with pure tumour regions. The original adjustment used 40 cell2location factors and 16 principal components explaining 90.8726% of variance. The full source reconstruction verified these quantities and refitted the composition model in this release. Source pathology categories and source cell2location factor estimates themselves were reused; deconvolution and original sequencing alignment were not refitted.

## Validation and outputs

Bundled `results/status.json` records the executed run. Numerical reference comparisons use `rtol=1e-9`, `atol=1e-11`, with equal missingness; strings and boolean memberships are compared exactly. Validation checks all 466 gene keys, all 159 non-key output columns, all three historical null summaries, the 441-test family, the 47/43/9/13 cardinalities, exact Convergent9 membership and nesting. The full H5AD and compact-source-count routes also passed, at `rtol=1e-8`, `atol=1e-10` for the source reconstruction followed by the stricter final processed comparison; their execution reports are in `validation/`. The patient/section checks are also supplied in `tests/test_scientific_invariants.py`.

The release includes compact source checkpoints in `data/counts/`: all 466 candidate count columns for the 20,654 spots, complete 36,588-feature library denominators, source coordinates and sample keys, the 40 raw q05 factor columns, and all 14 pathology CSVs. These files occupy approximately 13.2 MB. They allow the normalization, regional contrast, composition adjustment and coexpression calculations to be rerun offline:

```bash
python analysis/04_discovery_spatial/run.py --mode counts --output-dir results/04_counts
```

The raw H5AD is in `DeconvolutionResults_ST_CRC_BelgianCohort.zip` within Zenodo version 7760264. The **Belgian-reference archive** is required; the separate Korean-reference archive has a different composition model and H5 checksum. The provided downloader checks the public archive MD5 values and the recorded H5 SHA-256 before accepting inputs:

```bash
python analysis/04_discovery_spatial/scripts/download_source_inputs.py --output-dir /path/to/discovery_sources
python analysis/04_discovery_spatial/run.py --mode raw --raw-dir /path/to/discovery_sources --output-dir results/04_raw
```

`data/composition_adjusted_section_effects.csv` and `data/composition_adjusted_patient_effects.csv` additionally retain the newly reconstructed lower-level adjusted effects. The processed route continues to use the frozen summary checkpoints for speed; the counts route refits the adjustment from the included factors.

Principal outputs are `discovery_spatial_recomputed.csv`, `Moran_gene_tests_keyed.csv`, `patient_Moran_keyed.csv`, `spatial_patient_effect_summaries.csv`, `frozen_gene_sets.json`, historical null replay statistics, four panel source-data CSVs, and SVG/PNG Figure 4. The reference SVG supplied by the user is retained separately at repository level; the module generates a new renderer from the current source values.
